# 材质、文字明度与悬浮导航

用于已授权的视觉细化。先继承布局和任务；极简可降低材质强度，但不能自行取消下述主卡与导航合同；用户明确要求全平面或指定还原稿冲突时，记录具体例外。

## 前景与背景成对确定

不要把“橙色”直接等同于浅色或深色。为每种实际表面指定 `surface` 与 `on-surface`，深底用浅字、浅底用深字，随后测量。WCAG 相对亮度 L 下，白字对比为 `1.05/(L+0.05)`，黑字为 `(L+0.05)/0.05`；其他文字颜色按两个实际亮度计算。正文至少 4.5:1、大字至少 3:1。引用：[文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

用户选白字时，如果原品牌填充太亮，可以在同色相中加深承载文字的表面；不能机械只改字色。配色示例：`#FF5900` 对白字约 3.14:1，不适合普通小字；`#D34200` 对白字约 4.62:1，可作为深橙表面的亮端。保留鲜亮橙作深底上的强调色，两个 token 不必相同。

渐变要检查**所有文字覆盖区域的最差对比**，不能拿整张卡片平均颜色验收。亮边应留在边缘，不能穿过文字。图片或玻璃的背景会变，测试滚动后的亮/暗内容；必要时提高材料不透明度或增加稳定的文字底层。不要把彩色阴影算成文字背景。

## 用材质解释层级

本作者的无稿默认是：**每个有内容的页面必须且仅有一张突出材质的主卡，移动悬浮 Tab bar 必须另有液态玻璃外壳**。先确定承担主要信息的主卡，再给它渐变、内高光或方向性阴影；其他内容以纯色、间距、排版和边界区分。从已有主要内容选择主卡，不编造装饰数据或新功能。纯空态没有内容卡时可记录不适用，不能把普通完整页面当作例外。已确认稿、品牌或用户明确指定的例外优先。

常规主按钮、返回/关闭、保存/取消、图标按钮、筛选和导航选中胶囊都使用纯色填充或透明底，不叠玻璃、渐变、内高光和投影。可保留状态色、焦点轮廓、必要边线与普通按钮按压动画；Tab 不添加悬停填色或按压缩放，选中底色与文字/图标成对设置，键盘焦点仍可见。检查按钮内部的图标底托和 `::before/::after`，不能只删除主背景却留下高光壳。

| 层级 | 可采用 | 控制 |
|---|---|---|
| 页面底 | 稳定中性纯色 | 不与主卡竞争，不无任务依据地满屏流光 |
| 普通内容卡 | 纯色、必要分隔线、清楚间距 | 不重复主卡的渐变、内高光和装饰投影 |
| 唯一重点内容 | 按参考选择同色渐变、细内高光或柔和环境影 | 一页必须一张突出的内容主卡，纹理不可盖字 |
| 页面内常规主按钮 | 清晰的纯色填充、胶囊轮廓与按压反馈 | 不因“高级”默认叠玻璃、渐变、内高光和投影；先用纯色建立主次 |
| 移动悬浮 Tab bar | 液态玻璃：透射模糊、饱和度、边缘高光、内反光与悬浮影 | 独立导航层，不占内容主卡名额；选中按钮仍纯色，图标文字不随容器降透明度 |

阴影、渐变、纹理各自回答“哪里受光、离背景多远、承担什么层级”。主卡与液态玻璃导航必须同时出现；导航负责空间悬浮，主卡负责内容重点，其余区域平面化，不把玻璃做成全屏覆盖。弹层出现后，背景由遮罩退后，前景按相同规则分配主次。材质精简不等于去掉交互反馈，保留已确认的基础动效。

执行“所有页面统一”时，检查全部 Tab 与详情、历史、设置、表单、空态、选中/收藏、计时和完成弹层；不能只修用户圈出的一个按钮。逐一检查最终计算样式、伪元素与实际画面，先改共享组件规则，再处理少量专属覆盖。不要叠加全局 `!important` 掩盖旧规则。

研究时已审阅 [ccl125/liquid-glass](https://github.com/ccl125/liquid-glass/tree/8bfc4a3f457ed33c32c26e2c2ccf3db5cf932978)，MIT，源版本 `8bfc4a3f457ed33c32c26e2c2ccf3db5cf932978`：`core.js`、`map.js`、`liquid-glass.css`。其实现提供 SVG 背景位移与边缘高光。skill 包不附该库实现，仅保存方法与 [许可证](../licenses/liquid-glass-MIT.txt)，不自动安装或执行外部库。采用时审阅代码、固定版本、保留许可，优先按需文件，不为一个视觉效果替换现有技术栈。

浏览器对 `backdrop-filter` 的 URL 支持不能只凭 CSS 语法解析断言。分别记录实际测过的环境；不支持折射时使用磨砂模糊或实色回退。实现 `prefers-reduced-transparency`、`prefers-contrast` 和 `prefers-reduced-motion` 的对应回退。未测 Safari/真机时不得声称原生 Liquid Glass 或全平台相同光学效果。

## App 底部导航

无稿 App 存在 Tab bar 时，必须使用**一个具有液态玻璃质感的底部悬浮胶囊**：统一承载所有 Tab，而不是每项各自悬浮、外容器仍铺满屏宽。给左右与底部留空，外轮廓为完整半圆端帽，考虑安全区域。不能以不同风格词自行豁免；用户明确指定的例外或还原稿除外。Web 侧栏不套用移动导航。

内容可在悬浮导航下方滚动，但滚动末端应有足够 padding，使最后一行、主按钮和键盘焦点能完整到达导航上方。验证四个 Tab、滚动到底、窄屏和弹层；选中态有可访问语义、图标与标签，不仅依赖颜色。导航图标粗细和按钮材质保持一致。

## 2px 开源图标

选择有真正描边的开源 SVG，例如 [Lucide](https://github.com/lucide-icons/lucide)。研究时核查版本 `500620a2e8123f8d1db191538886dc0c223f69a9`，上游 [许可](../licenses/lucide-LICENSE.txt) 随包保留。保留原路径，不通过给填充轮廓追加 stroke 来冒充 2px。

以实际显示尺寸核查：`fill:none; stroke:currentColor; stroke-width:2px; stroke-linecap:round; stroke-linejoin:round`。不同大小仍需精确 2 CSS px 时，对路径/圆/线等几何元素设置 `vector-effect:non-scaling-stroke`。仅在 24 viewBox 写 `stroke-width=2`，缩放到 18px 后会变成 1.5px，不能据此宣称统一 2px。

保留来源、提交、许可证；核查实际几何元素的计算样式、变换和渲染。2px 是本作者的默认设计约定，用户稿或已有品牌另有明确要求时遵从其要求。
