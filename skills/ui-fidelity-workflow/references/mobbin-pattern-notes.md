本次沉淀：任务结构先于装饰；明暗区分主次；强调色承担操作语义；状态使用不止一种视觉信号。没有把公开预览当成所有现代 UI 的代表，也没有将遮罩后的像素当产品 token。

作者另外选择“无稿默认高饱和主题色、强黑白对比、排除米黄人文风”，具体执行见 [无稿设计](modern-product-ui.md)。这是本 skill 的取舍，不是 Mobbin 的统一规则或官方建议。新任务可参考更多获准访问的样本，但不能声称已学习未查看的内容。
