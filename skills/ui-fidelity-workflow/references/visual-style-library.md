# 开放的视觉风格参考库

风格与产品品类分开选择。先确认任务和用户偏好，再组合排版、构图、颜色关系、材质及内容表现；不能把跑步一律解释为黑橙大数字。这里是研究入口，不是封闭选项或热门排行榜。

2026-10-05 扩展到专注、时间工具、音频、电商、摄影、作品集、软件工具与品牌网站。新来源的画面事实、证据类型和访问限制见 [公开证据册](reference-atlas.md)。旧有 Apple、Linear、Headspace、Nike、Runna 记录保留，但不再由运动案例决定整套风格。

## 三个维度组合

| 维度 | 要决定什么 | 可用检索词 |
|---|---|---|
| 视觉方向 | 页面怎样组织主次、传达气质 | editorial, Swiss grid, typographic, minimal, playful, neo brutalism, cinematic, retro digital |
| 组件模式 | 用户看到什么、做什么、处于什么状态 | timer, calendar, progress, player controls, catalog, data table, map sheet, filter, confirmation |
| 材质与表现 | 如何处理表面、光照、边界和图像 | soft gradient, atmospheric glow, frosted glass, tinted glass, layered shadow, flat outline, monochrome, photographic |

`柔和渐变 + 运动计时`、`编辑排版 + 金融信息`、`极简 + 学习进度`都可以成立。先找相同任务，再跨品类找相同组件，独立补视觉参考。做法见 [跨品类组件检索](cross-domain-components.md)。材质词不是完整信息架构，不因选了玻璃就给每个区域加玻璃。

## 18 个可继续扩展的方向入口

下列是从已查看画面归纳的分类，不是来源网站对作品的统一官方命名。不同入口可以组合，不把行数当成互斥风格数量。ID 对应证据册。

| 方向 / 关键词 | 已观察参考 | 可借用的关系 | 适用边界 |
|---|---|---|---|
| 极简排版 · minimal, quiet, whitespace | G3 X Advertising；用户给定 Apple-like 配方 | 简单导航、内容分区、单一主操作、克制表面 | 用户明确极简时，不主动添炫光、厚重阴影或纹理；留白不能挤走任务 |
| 编辑式网格 · editorial, Swiss grid, index | G8 Harry Atkins；D7 Travel | 对齐分栏、目录、编号与字号反差 | 作品/知识/集合页；不继承过小灰字或额外字体 |
| 巨型排版 · oversized type, type as image | G5 Shopify Design | 标题成为视觉主角，局部图像与字形交织 | 发布、品牌、作品首屏；不能妨碍任务阅读 |
| 柔和渐变 · soft gradient, atmospheric | D1 Focus Timer；R2 Touch Time | 柔和彩色环境配稳定内容面，主要数字突出 | 专注、时间、生活、运动都可用；渐变不等于低文字对比 |
| 轮廓色块 · outlined UI, neo brutalism | D3 Bruddle | 清楚边框、平面色块、紧凑行、彩色状态 | 工具、创作者、教育；直角按钮不覆盖用户胶囊要求 |
| 石墨工作台 · graphite, dark workspace | [Linear](https://linear.app/now/behind-the-latest-design-refresh) 已核查设计更新图 | 导航与内容层次、柔和边界、减少重复容器 | 密集工具；暗色不降低关键文字对比 |
| 精密信息界面 · structured, compact, data-rich | G9 Interfere；D3 Bruddle | 属性列、记录流、筛选/状态与明细关系 | 工作台与分析；营销包装不等于业务页本体 |
| 玻璃空间层 · translucent, floating, glass | [Apple 软件设计](https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/) Music 图；R2 | 浮动控制与内容层分离、透明边缘和高光 | 导航/工具层；正文卡不全透明，跨浏览器需实测和回退 |
| 摄影画廊 · photo-led, gallery, asymmetric | G7 Gregor Collienne | 异尺寸图片、留白与中心信息的节奏 | 摄影、旅行、内容探索；需有可用图源 |
| 沉浸叙事 · cinematic, full-bleed, art-directed | G4 Shopify Editions | 全幅场景承载主题，局部目录控制入口 | 专题、展览、发布；不替代日常工具的任务结构 |
| 展厅式电商 · showroom, object-led, catalog | G10 Becane Paris | 同尺度商品阵列、大片留白、克制分类入口 | 商品/服装/收藏；购买、筛选、价格需另补依据 |
| 插画色块 · illustrative, playful, bold blocks | [Headspace App](https://www.headspace.com/app) 已核查 Guided meditations 图 | 分类插画与内容标签共同识别入口 | 学习、健康、内容；插画有来源，图标仍用统一开源 SVG |
| 桌面隐喻 · desktop metaphor, widgets, dock | G6 Displace | 工作空间、工具小组件、文件与导航分层 | 工作台、个人站与创意工具；手机端需重组，不搬系统商标 |
| 复古数字 · pixel, terminal-like, retro digital | G12 Astro Dither 入场帧 | 少量像素形态与数字设备气质 | 仅视觉线索；没有完整流程证据，不假装已验证交互 |
| 空间主视觉 · spatial, 3D-led, depth | G1 Nothing to Watch；G2 Augen | 内容深度、中心焦点，功能层保持简单 | 探索、产品展示；静帧不证明 3D 引擎或动画，实现需性能/可访问回退 |
| 沉浸式媒体 · immersive media, dark player | R3 untitled；Headspace Sleep 已核查图 | 内容主视觉、进度和主要播放动作分层 | 音频、课程、录制；快进/循环不能迁移到不相关任务 |
| 模块化目标 · milestones, goal progress | M3 Mobbin 阶段预览；[Runna](https://www.runna.com/) 已核查计划图 | 阶段、当前进展、辅助指标与下一动作 | 学习、储蓄、训练；模块按任务生成，不凡界面皆卡片 |
| 强数字仪表 · metric-led, high contrast | R2 Touch Time；[Nike Run Club](https://www.nike.com/nrc-app) 已核查记录图 | 关键数字占主层，次要信息与控制分组 | 计时、能耗、分析、运动；所有指标不能同权放大 |

## 选型与统一

选择一个主要构图与排版体系，再用相容材质和组件补足任务。不要将五个来源的品牌色、不同字体、导航语义和密度一起保留。用户已确认 PingFang、胶囊按钮、2px 开源描边图标时，这些仍是统一条件；引用某种风格不自动授权改掉它们。

同一产品可以按页面角色调整表现强度：探索页使用摄影，详情页突出阅读，操作页减弱装饰，但保持字体角色、间距、控件与色彩语义一致。用户要求极简时，以必要信息、可靠控件和克制表面实现，不因库里有更多方向就增加装饰。

明确的柔和渐变、低饱和主题等选择优先于作者默认的鲜明主色偏好。柔和应体现在环境与材料，文字对比及操作辨识仍要检验；不要以“现代 UI”为由偷偷改成高饱和运动风。

## 继续研究的规则

按需检索用户指定网站：Mobbin/Refero 找真实页面与状态，Dribbble 扩展概念和视觉处理，Godly/其当前公开去向补网站构图。来源角色不是绝对分类；逐条核验是产品屏、概念稿、官网展示还是策展静帧。

每条新增记录包含「URL与日期 → 可见事实 → 可迁移关系 → 目标组件 → 不适用条件/未知状态」。只有文字、标签或摘要的候选不能升级为已看过的画面。Claymorphism 等本轮图片未成功取得的方向保留为待查关键词，不填充到已核实表里凑数。

覆盖关键任务与状态后结束检索。没有匹配的整屏就拆组件，不等于改变产品或放弃已确认风格。实际实现再按 [材质与对比](materials-and-contrast.md) 和 [验证](verification.md) 检查；研究截图不进入 skill 分发包。
