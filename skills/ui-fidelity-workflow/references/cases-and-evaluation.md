# 经验案例与情境检验

案例提炼自真实产品的 UI 协作迭代，已去掉项目标识、私有正文、人物数据、地址和凭据。现象与需求来自实际反馈；没有逐一重审历史源码，不将候选原因写成已证实根因。

| 观察/要求 | 可复用教训 | 不能断言 |
|---|---|---|
| 渐变下面又出现文字，碰到“收起” | 正文范围受按钮间距约束，分查裁切和渐变 | 必然只缺 overflow 或 line-clamp |
| 收起终点正确，中途底边下坠 | 联测位置高度，验全过程 | 必然是弹簧或某动画库的问题 |
| 玻璃变灰时突然消失 | 先查退出生命周期，再做透明度过渡 | 必须新增 wrapper，所有产品都该用玻璃 |
| 聊天/系统返回闪一下 | 查共享交接和一级页准备，按钮手势都测 | 现象相同必然根因相同 |
| 整卡可点 | 扩大触发区，保护按钮、选字、滚动 | 展开后点正文必须收起 |
| 仅聊天窗显示滚动条 | 按实际滚动容器设置例外 | 其他页应禁止滚动 |
| 优化现有代码，其他不动 | 明确维护入口，局部收敛职责 | 所有 wrapper、覆盖、旧文件都可删 |

## 用例

以下用于人工或独立评估，不代表已完成浏览器验证。委派、联网和发布遵守宿主授权，skill 自身不授予这些权限。

1. “返回会闪，先检查不动手。”应输出证据/假设/局部方案，不能写产品代码或部署。
2. “高级一点，其他不变。”应读指定区域和现有风格，问影响方向的直观问题或做局部样本，不能全站玻璃化。
3. 只有大文件 Figma 链接、目标名不唯一。应定位节点版本并分区读取，不能猜画板或声称完整读取。
4. 同一修复两次无效。应核验加载版本、元素和生效属性，不能追加第三个 `!important`。
5. 起点 top=120、height=600；中途 top=350、height=430；终点 top=400、height=200。应发现中途 bottom=780 超过起点 720；还需确认坐标系和滚动。不能因高度一直缩小判通过。
6. 玻璃元素切换同帧被卸载。应查退出时机，而非只给消失的元素加 transition。
7. 隐藏滚动条、聊天除外。应保留滚动与键盘访问，不能全局 overflow hidden。
8. 删无用 CSS，保留指定版本回滚。应证明失效、保护回滚及运行构建，不能按日期全删。
9. 只改摘要标签。应局部修改并看显示，不重构聊天页。
10. 无浏览器或设备。应说明哪些检查完成、哪些效果未测，不能报告真机流畅。

skill 的格式验证不证明上述决策正确；需用实际任务迭代。出现反例时局部修订，避免不断添加普遍禁令。

## 无稿执行合同的反例回归

以下来自一次未合规执行的音乐产品测试，用来阻止复发，不是效果提升证据。

| 情境 | 必须行为 | 失败信号 |
|---|---|---|
| 新账号只安装本 skill，没有作者协作记忆 | 入口读到完整硬约束，再加载无稿必读参考 | 依赖“你应该记得我偏好”或仅查看目录就开画 |
| 协调者公共 brief 写“布局、字体、圆角自由”，但用户显式使用本 skill | 公共 brief 只约束任务，沿用明确的 skill 设计合同；真正用户明确冲突则按用户要求 | 将自动添加的自由设计句子当作豁免 |
| 主按钮已胶囊，筛选、版本选择、确认弹窗仍小圆角 | 检查全部可操作按钮的实际边界，逐项修正 | 只抽查主 CTA、仅查 class 名 |
| 黑白酸绿产品把浅底写成黄绿灰 | 大面积非强调背景保持中性 RGB，不把主题色混入底色 | 用“接近白”掩盖偏米黄/黄绿 |
| 手机三页有 Tab Bar | 同一悬浮胶囊保持离边间距，内容末项能滚到其上方 | 桌面侧栏通过就算手机导航通过；手机底部通栏 |
| Mobbin 付费不可达，已授权公开替代 | 明示访问受限，实际查看官方界面截图并逐组件映射 | 把来源名、文字说明、营销页当作已观察组件 |
| 页面含 transition / 动效工具，但截图仅终态 | 检查页面/按压/新内容真实触发的中途帧；记录 reduced-motion 与中断结果 | 用 CSS 字符串或静态截图宣称流畅 |
| 功能 32/32 通过，但上述规则未通过 | 将处理组标为执行不合规，保留失败样本，不推导 skill 效果 | 据功能同分宣布 skill 无效或声称差距证明美观程度 |

- “完成页面后加基础动效”：按组件任务选用切换/点击/进入/数字/路径配方，交付实际可运行效果；不重新询问已确认风格，不强加五类全覆盖。
- “开始跑步按钮用普通填色”：只移除目标按钮的渐变、高光、阴影及图标底托，保留胶囊、可访问名称与动作；不删除其他卡片材质，不扩成整站动效工程。
- 快速从 A 切 B 再切 C：C 成为最后页面，B 的延迟结束回调不能卸载 C，焦点和滚动保持合理。
- 数据 9.9 → 10.0 → 8.2 密集更新：最终值是 8.2；数字与单位不串位，不用视觉副本作为业务真值，不每次从 0 重播。
- 系统已开启减少动态效果：数字直接终值，SVG 保留完整原图；仍有清楚操作与状态反馈。
- 已有动画库或 Figma 动效：沿用既有规范，只添加需要的行为；不强制安装新依赖或覆盖已确认设计。

## 新分支的回归情境

以下是验收目标，执行结果须另记，不是已通过的宣传数据。

| 输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| “无稿做一个手机阅读首页，继续阅读、搜索、书架” | 保留产品与平台答案，追问未给的风格和主题颜色，回答后检索并观察参考 | 未确认就套高饱和或米黄；重新问已知产品 |
| 四项都已回答：跑步四 Tab、大胆、活力橙、iPhone App | 需求映射组件，实际查看跑步/训练/社区/个人参考后实现 | 重问四项；把可选 Apple 极简提示当当前风格 |
| “专业风格，品牌蓝，Web 数据工作台” | 尊重蓝色与专业方向，查匹配参考 | 因作者偏好强行换橙色或做移动端 |
| Mobbin 无连接但公开官网有参考 | 使用公开来源并标注实际查看范围 | 假装访问 Mobbin 登录内容 |
| 用户未回答主题色 | 等待关键答案，继续需求整理等独立工作 | 用沉默或预选值当确认 |
| “Figma 米黄底和衬线字是已确认品牌” | 忠实还原，诊断差异 | 用无稿规则强行换黑白/无衬线 |
| “现有米黄页面，只修按钮对齐” | 最小局部修改 | 因没有 Figma 而重设计全页 |
| “卡片做成 3/4” | 主动确认维度与参照物 | 默认为 viewport 的 75%，用户纠正后才问 |
| “点开更自然” | 结合已知状态给具体选择，询问未知的交互含义；已知目标不重问 | 只调 duration 或发一串 CSS 参数问卷 |
| 全部设计上下文已落盘，仅工具显示截断 | 读取必要片段，确认缺口后才重取 | 无限拆节点重复请求 |
| 根容器高度与视口不同，导航偏移 | 量祖先与导航，修高度来源 | 给每个子元素手工补相同偏移 |
| 字体文件 loaded，但关键汉字仍回退 | 核查实际渲染字体或明确未确认 | 将资源 loaded 当成无回退证明 |
| 无稿要求避免蓝色、PingFang、胶囊按钮、开源图标 | 检查真实字体、全部按钮状态的半圆端帽、SVG 来源；采用非蓝主色 | 只改主按钮、只写字体名、自己画图标或留下灰色开发说明 |

材质分支追加情境：用户要求深橙卡白字，应同时核查背景亮度与小字对比；要求实际 2px 时，不给填充图标强加外描边；悬浮导航出现后要验证末项能滚到导航之上；仅给出极简风格词时收敛材质强度，不自行取消主卡和玻璃导航；明确全平面要求则记录用户例外。

## 跨品类检索情境

以下仍是待执行的行为验收目标，不是质量提升实验结果。

| 输入 | 应观察的行为 | 失败信号 |
|---|---|---|
| 柔和渐变的运动 App，四项明确，同领域没有合适画面 | 分查运动任务、专注/时间工具的计时组件及渐变视觉，保留运动语义 | 改黑底荧光色；宣称市面不存在；因无整屏参考停止 |
| 自由跑记录借鉴番茄钟 | 借数字与控制组，保持正计时、暂停继续结束 | 自动加入 25 分钟倒计时、强制休息或白噪音 |
| 极简学习 App 借会员进度组件 | 保留阶段进度与学习任务，克制材料 | 自动加入促销、积分商城与复杂玻璃效果 |
| 专业财务工具希望柔和渐变 | 信息密度和表格语义由财务任务决定，环境色从其他品类借鉴 | 因财务默认蓝色；用大面积渐变掩盖金额或状态 |
| 多个品类提供组件 | 统一间距、字体、主题、动作层级，记录结构与视觉各自来源 | 每块保留不同品牌色/密度；声称找到一款完整竞品 |
| 只有 Dribbble 概念稿，未知交互 | 仅据图判断外观，补查状态或明确适配部分 | 将概念稿称为已上线/已验证；编造动画与后台 |
| 登录限制或网站重定向 | 保存实际访问范围和可见证据，使用公开替代 | 绕过限制；把 Godly 搜索摘要当本轮当前页面 |

对比新版与旧版时固定需求、模型、工具、预算、资产和视口，记录额外追问及回答；两组采用独立上下文，避免把 skill 方法提前写进公共提示词。首稿与修订稿分别留存。视觉偏好使用隐藏组别的同条件图片评审，功能与几何另测。无稿没有唯一参考图，不能用“像素还原率”评价创造性。至少报告样本数和未测项，不从一个更鲜艳的样本推导稳定优势。


## 对齐与导航状态回归

- 圆圈内数字使用猜测坐标：改为以圆心锚定，逐个核查不同数字的几何与光学中心，不只验外框。
- 未选中 Tab 悬停出现黑底黑字：检查移动端与桌面规则的层叠，移除不需要的 hover/按压装饰；选中项、焦点和禁用状态仍分别可辨。
- 动画中 Tab 上弹：按布局诊断逐帧量导航与视口，检查临时横向滚动条，不靠改变 bottom 或删除全部动画掩盖。
