# 还原偏差：从现象找到原因

只在对应症状出现时读对应行。表中是候选原因和验证方法，不能看到症状就宣布根因。先固定来源与运行条件，再记录“一条假设 → 一个可区分原因的测量 → 最小修复 → 同条件复验”。

## 先分类，再动代码

- 多个子元素整体同向偏移：优先查共同祖先的位置、尺寸、滚动和 transform。
- 从某一行开始，后续元素逐渐偏移：优先查字体、换行、行高、gap 和盒模型的累积。
- 几何正确但颜色或质感不对：查透明度叠加、背景、描边和资源范围。
- 初始正确、加载后或操作后失真：查字体/图片布局变化、状态更新与动画交接。
- 原稿本来如此：标明原稿现象。还原任务不擅自“修正”源设计；影响使用时提出具体差异。

## 静态诊断表

| 症状 | 区分原因的证据 | 最小修复与复验 |
|---|---|---|
| 底部导航提前、根画板比目标矮 | 同时量 viewport、根容器、内容区和导航 rect；查看 `height:100%` 的包含块是否有确定高度 | 在实际负责画板高度的层修约束；固定尺寸原型可明确高，真实页面按动态视口/内容规则处理。别先给导航补负 margin；长内容复验 |
| 按钮在屏外或一整块突然不定位 | 查看 computed top/left、包含块、控制台、CSS 声明是否有效，核对 `calc()` 运算符格式 | 修无效表达式或错误定位父级。再次量 rect 并实际点击；“DOM 存在”不代表可操作 |
| 代码看着有样式但元素没生效 | 对照渲染 DOM 的 class、框架语法、选择器和实际样式入口 | 检查 JSX→HTML 时残留的 `className` 等转换错误；改真正入口，不增加重复规则 |
| 字像对了，但换行/按钮宽度不同 | 核对实际使用的字体、字重、行高、字距；变量字体轴和命名实例；对比代表性中英文字 | 字体 loaded 仅表示资源可用，不证明该元素没回退。修字体/轴/度量，再量文本；不改原文或塞 `<br>` 掩盖错误 |
| 数字与单位分离、局部字距异常 | 检查内联节点之间的真实空白、断行机会和字距继承 | 有语义需要时使用不换行空格或局部 nowrap；不要给整段正文禁换行 |
| 画板尺寸相同却越往下越错 | 按首个偏差点向后量高度、行数、gap、padding、border；检查小数坐标累积 | 修产生偏差的上游值；保留必要小数，避免每行取整或逐块补偿 |
| Fill/Hug 映射后挤压、横向溢出 | 检查父容器宽、flex shrink、min-content、`min-width`、grid track；使用长标题复现 | 主内容按布局关系用 Flex/Grid；需要收缩的子项可设 `min-width:0`。不要仅用全局 overflow hidden 隐藏内容 |
| 框比稿大一圈，圆角边缘不对 | 分清设计里的内/中/外描边、CSS border 盒模型及描边是否占空间 | 正确映射 box-sizing、border 或不占位的绘制层；复验内容尺寸，不只看外缘 |
| 图标偏位、光晕被截、图片留白 | 比较 SVG viewBox/固有边界、导出范围、容器 rect、object-fit、clip | 复用正确原始资源，修容器或裁切范围；不要因轮廓近似而用 emoji 替代 |
| 背景色相似但玻璃/阴影发灰 | 比较实际背景、父子 opacity、遮罩、blur 与变量继承 | 在负责材质的那层修透明度或变量作用域；避免父层 opacity 顺带淡化正文 |
| Figma 标注色与画面不同 | 确认变量 mode、实例覆盖、variant，以及半透明在何种底色上合成 | 使用当前实例/主题的有效值；不要只抄主组件或 token 名 |

## 动态与交互诊断

| 症状 | 思路与验证 |
|---|---|
| 卡片终点正确，中途下坠 | 联合测 top 和 height：`bottom=top+height`；明确屏幕/容器坐标与滚动。位置和高度分开动画可能合成错误轨迹。详见 [运动与布局](motion-and-layout.md) |
| 加载一瞬间闪位 | 分开字体、图片固有尺寸、异步数据和滚动恢复的到达时刻；保留空间或修更新顺序，不用长遮罩隐藏 |
| 关闭突兀、返回闪一下 | 查退出生命周期、旧新视图交接和取消/反向操作；在开始、中途、终点观察，不只加 transition |
| 鼠标能点、键盘看不到焦点 | 实际 Tab 到目标，看最终 outline/box-shadow 是否被内联样式或裁切覆盖；能 focus 与能看见是两项 |
| 视觉一致但点击无结果 | 核对状态所有权、命中区、遮挡层和事件；区分本地原型反馈与后端完成。不能把展示态算作功能通过 |

## 对照时不要误判

同视口、同内容、同字体状态、同滚动位置比较。先记录主要锚点的 x/y/width/height 与文本换行，再看截图差异；平均像素误差会被大片空白稀释，抗锯齿也会放大文字差异。图片指标、关键几何和操作结果分别报告。

两次修复都无效时停止叠加补丁，核查是不是旧产物、错误实例、被覆盖的声明或双状态来源，见 [排查与清理](debugging-and-cleanup.md)。

以上包含实际对照中暴露的百分比高度、无效定位表达式、代码转换和变量字体问题，也包含通用排查假设；它们不是对任何当前项目根因的预先结论。
