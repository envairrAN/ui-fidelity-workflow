# 基础动效模块

在界面与功能成立后完成并验证，不靠动效掩盖布局、数据或反馈缺失。新建无稿交互页面必须接入页面切换、按压反馈、新内容进入三类基础动效（有对应触发才适用）；有真实数字变化或完成图标时再接入滚轮与路径。时间不足不能把动效降为口头建议，须标记交付未完成。保留用户明确的无动画要求、减少动态效果设置、项目已有规范与 Figma 动效；局部修改不顺便给整个产品加动画。

## 五类配方

参数是可调整的起始值，不是从参考产品测出的数值。已有 token 优先；数字与图标可以有一次短暂强调，其他常用交互保持轻快。

| 动效 | 何时采用 | 默认实现 | 返回、中断及边界 |
|---|---|---|---|
| 页面切换 | Tab 切换、进入详情、返回 | 同级页面 160–220ms 淡入；有层级的前进/返回可加相反方向 10px 位移，保持导航壳固定 | 路由立即响应；快速切换以最新请求为准，旧回调不能覆盖新页；恢复滚动与焦点；不每次整屏重演 |
| 组件点击 | 主按钮、筛选等可操作控件 | CSS 按压缩到 .98，120ms 复位，纯色按钮也可使用 | 不等动画结束才执行动作；禁用态不动；保留键盘焦点；hover 只对精细指针启用 |
| 组件进入 / 退出 | 新出现的卡片、弹层内容 | 220ms 的透明度 + 8px 上移；退出沿来路 160ms；同组必要时 40ms 错峰，总延迟不超过 80ms | 普通重渲染不重复进入；清理动画；已有弹层库继续管理焦点、遮罩和关闭，不自造第二套弹层 |
| 卡片数字滚动 | 一次数据刷新、用户操作后的汇总变化 | 从之前的真实值到新值，变化位上下滚动约 280ms；等宽数字、固定单位与可用空间 | 首次加载可直接显示；从旧值继续，不每次从 0；连续更新直接落到最新值；实时计时、输入金额不滚动；不伪造统计进度 |
| SVG 图标路径生长 | 一次完成、确认、里程碑反馈 | 原 SVG 描边用 dashoffset 呈现路径，260ms；多段最多延迟 60ms | 沿用开源原路径与 2px 线宽，不自画图标；非描边、填充、原虚线图标改用短淡入；导航和普通按钮不每点击就重新描线 |

默认缓动：`cubic-bezier(.23, 1, .32, 1)`。只动画需要的属性，不用 `transition: all`；位移优先 transform/opacity。路径描边会发生绘制，因此只对少量短路径使用，不把它说成纯合成动画。常规界面不自动加入无限脉冲、流光、全屏视差或复杂滚动叙事。

## 选择实现方式

有 Motion、GSAP、原生平台动画或项目组件系统时，沿用其状态与生命周期。没有动画依赖时，CSS transitions + Web Animations 足够覆盖此处基础配方，不为了淡入新增包。原生 iOS/Android 使用对应平台能力，下面的 Web 代码不能直接当作原生实现。

包内 [motion.css](../assets/motion/motion.css) 与 [motion.mjs](../assets/motion/motion.mjs) 是可选起点，不会自动安装或注入页面。只拷贝/改编本轮需要的功能，映射到已有 token，模块导入不会注册全局点击监听。`createUIMotion()` 才创建生命周期监听；卸载时调用 `dispose()`。时长 token 使用 `ms` 单位，传入的可动容器在静态布局中须为 `opacity:1; transform:none`；否则采用已有动画系统或一个必要的中性包装层。

```js
import {createUIMotion} from './motion.mjs';
const motion = createUIMotion();
// 按钮加 data-ui-press；只作视觉反馈，原 click 逻辑即时执行。
motion.enter(newCard);
// 仅包裹数字文本；单位放外面，数据来源与格式由产品层控制。
motion.rollNumber(numberElement, '24.8', '26.3');
// 给合法 SVG 的原始 path/line 等加 data-motion-path；不改 d。
motion.draw(successIcon);
// 组件卸载：motion.cancel(element)；页面整体卸载：motion.dispose()。
```

数字示例是实际逐位上下滚动，不只是把 textContent 从 0 递增。数字节点应有 `data-ui-number`，不能包含单位、图标或业务子节点；助手函数会替换其内容。动画期间给辅助技术保留一次最终数值，视觉副本 `aria-hidden`；不要把每个变化位放进 `aria-live`。原有实时播报应由产品层对最终结果播报一次。针对负数、千位、精度与位数变化保留最终格式；不可用动画位解析业务数据。

## 页面切换的接入顺序

1. 路由/Tab 状态为唯一权威；数据加载状态不能伪装成转场。普通同级 Tab 可先提交真实内容，随后对新容器 `motion.enter(panel, {kind:'page'})`，导航保持原位。
2. 若已采用入退场重叠，沿用现有 router/presence。旧页保留到退出完成时必须从焦点顺序和辅助技术中移除，避免两个可操作页面；不要给 body 全局 `overflow:hidden` 掩盖滚动问题。
3. 异步交接使用序号或 AbortController。`exit()` resolve `false` 表示被取消，只有它返回 true **且** 请求序号仍是最新时才能提交后续卸载；旧回调不得更改新页。示例模块不替调用方导航、删除 DOM、移动焦点或恢复滚动。
4. 高频键盘快捷操作即时执行；新页焦点按现有导航规范处理，不为装饰等待动画。纯 CSS :active 不改变业务键盘行为。

## 减少动态效果与失败回退

尊重 `prefers-reduced-motion`：取消位移、数字滚轮和路径描画；直接提供完整图标、最终值和清楚选中态。若项目已有必要的轻淡入可以保留，不能用“必须有动画”推翻用户设置。提供“关闭动画”设置的产品沿用该设置。

示例模块在偏好切到 reduce 或页面进入后台时结束当前视觉动画；在缺少 Web Animations 时直接显示终态。动画取消的 Promise 不应产生未处理拒绝；卸载清理资源。没有 JS 时，原始 HTML 也应显示最终内容，不能先全局隐藏等待动画脚本救场。

## 收尾验证

先列出“触发动作 → 实际目标元素 → 动画属性 / 时长 → 中途画面或录像 → 中断与终态结果”。只存在 CSS、帮助函数、可选资产或静态终态截图，不算接入或验证完成。不为了凑齐五类而伪造统计变化、进度或成功状态。

- 看真实中途画面或录屏：入口与退出、文字清晰度、图标路径是否正确，不能只看完成截图。
- 快速连续点 Tab、反向返回、弹层开关、退出中重新打开：最终状态与最新操作一致，不闪空页，不残留遮罩和失焦。
- 数字测试上升、下降、0、负数、小数、跨位数与密集更新；终值准确、单位不动、不反复播报；运行计时保持原本真实节奏。
- 切换 reduced-motion、滚动离开/组件卸载、后台返回：终态完整、无残留动画/监听器或未处理错误。
- 路径保留原 d、stroke、viewBox、许可与可访问名称，终态无半截图标。小屏、触控、键盘分别检查；浏览器模拟不等于真机测试。

## 方法来源与适用边界

此模块参考当前可用 `animate` skill 中的“目的 → 最轻工具 → 中断 → 减少动态效果”顺序，重新编写为本包自包含流程与代码；未捆绑整套第三方 skill，也不依赖作者电脑上的路径。可用时深度手势/弹簧工作可另外调用适用的动画 skill，不能把“已安装”作为前置条件。

Web API 语义核查于 2026-10-05：[Element.animate](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)、[Animation.cancel](https://developer.mozilla.org/en-US/docs/Web/API/Animation/cancel)、[prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)、[SVG stroke-dashoffset](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/stroke-dashoffset)。这些文档支持技术行为，不证明本 skill 提升了转化或审美评分。
