# 验收与交付

## 先检查 skill 是否真正执行

无稿新建界面先按 `SKILL.md` 的强制设计合同验收，再判断效果。交付一张简明的规则表，逐条给出通过 / 失败 / 未验证、不适用理由，以及浏览器测量、源组件并排证据或动画记录。不能只检查按钮“能点”、流程“能走通”。

- 胶囊：枚举全部常规按钮与各状态，测最终 rect、四角半径；检查伪元素，不只检查 CSS 变量。
- 对齐强制项：枚举重复组件中的文字、数字、图标与承载容器，逐个核对中心、同组基线、内边距和边缘，不仅检查外框。居中组件记录内容中心与容器中心的 x/y 偏差；SVG 编号先将坐标设为圆心，再明确 text-anchor 与基线。字体加载后在实际渲染尺寸检查；布局框居中仍须放大目视字形重心，必要时按实测字形作光学校正，禁止凭空堆偏移值。覆盖不同数字、文本长度、选中/未选中与移动/桌面尺寸；缺证据记未验证，不把大致居中记通过。
- 中性底：读取 body、主内容、普通表面的真实合成颜色并目视核对；米黄、奶油、黄绿灰不能当白/中性灰通过。
- 移动导航：各页面与较窄视口测左右/底部间距、半圆轮廓和滚动末端操作的可见性；贴底满宽矩形失败。
- 材质强制项：每个有内容的页面必须恰好一张突出材质主卡，移动导航必须同时具备可见的液态玻璃外壳，两者不能互相抵消。记录主卡选择器；检查渐变、高光和投影，并目视滚动前后背景透射与文字对比。仅声明 backdrop-filter 或白底加阴影不算视觉通过；不支持透明效果时单独验证可读回退。普通按钮保持纯色。
- 导航切页稳定性：在普通动效和 reduced-motion、常规及窄手机尺寸下，用真实点击测试每个 Tab、滚动后切换和快速连点；逐帧记录导航 rect 与根节点 scrollWidth/clientWidth、clientHeight。视口不变时导航 y/高度不得跳动（仅容许 0.5 CSS px 测量误差），中间帧也不得产生横向溢出或临时滚动条。键盘或真实视口变化单独判断；不要通过禁用全部动画掩盖问题。
- 交互颜色：分别查看默认、hover、active、focus-visible、选中与禁用状态；背景和文字/图标成对核查，禁止黑底黑字。未选中 Tab 不出现悬停填色或按压缩放，键盘焦点提示必须保留。
- 字体与图标：核实实际使用的 PingFang 字形；SVG 保留原几何与可追溯来源，并测 2 CSS px 线宽。
- 需求与组件：对照实现前的任务/来源表逐项查看结构；主控件缺实际画面证据，不能称参考驱动完成。
- 动画：普通 motion 设置下观察起点、中间、终点或录屏，验证页面/按压/进入以及适用的数值/路径动效；另测 reduce 与连续操作。最终截图不能证明流畅动画。

可用 [browser-contract.mjs](../scripts/browser-contract.mjs) 作为只读几何诊断起点：在页面上下文执行 `auditUIContract({buttons, surfaces, navigation})`，显式提供项目真实按钮/普通表面/导航选择器。它读取按钮实际边界与角半径、表面 RGB、悬浮间距和溢出，不引入依赖。需覆盖弹层、生成后等状态，不能把选择器缩小到少数通过的控件。实际字体、图标原始几何、材质主次、参考来源和动画必须另验；脚本会将这些保留为未验证，不能自动生成全通过结论。

对照实验将“执行合规”和“产物效果”分开。未正确执行 skill 的产物属于执行失败证据，不能直接当作合格处理组证明 skill 有效或无效。原始记录保留；修订 skill、补充参考或增加预算后的重跑单独标明，不能混入原组挑优比较。公共任务不得包含抵消 skill 的额外提示，例如给有 skill 组写“字体/圆角规范可不采用”。

## 匹配风险的验证

- 改文案/局部颜色：看显示、换行、目标规则与 diff，不默认全量构建。
- 布局/裁切：长短内容、目标视口、滚动/按钮，必要时加项目类型检查。
- 动画/手势：起点、中途、释放/中断、终点、重复触发；测硬约束也看录屏。
- 全局 token/CSS、路由交接：检查直接受影响页面、主题与断点，运行必要回归/构建。
- 发布：按项目流程核验产物和远端加载版本，抽查本轮目标；上传成功不等于发布成功。
- 无稿新界面：执行 [无稿设计的五项自检](modern-product-ui.md)，保存真实渲染及主要操作状态；分别判断风格、任务层级、可用性，不虚构“还原分”。

## 对照条件

固定视口、缩放、主题、字体、内容、滚动位置与动画状态。先比较比例层级，再查几何、排版、材质。记录基准来源；别把系统抗锯齿差异当布局错误。

端点截图会漏闪帧和路径越界。用允许的工具记录逐帧 rect、scroll、opacity 和状态；慢放看材质/交接。不能绕过工具自身的执行限制。

保存触发时坐标，明确坐标系，记录页面滚动。检查本轮真正相关的点击/手势、取消/提交、连续触发、长短文组合，不机械穷举应用。

数学推导、模拟帧或桌面通过不等于真机通过。移动 Safari 未测就写未测；相邻新问题判断是否属于本轮因果链，无关项记录后另行处理。

## 功能与交付

检查命中区、焦点、键盘、选字、滚动与既有可访问语义。保留真实接口；原型示例数据需标注。不能为截图外观悄悄移除加载、错误或长文本状态。

交付可写：“已修改 A，解决 B；在 C 条件观察到 D；E 尚未验证。”

还原度没有统一百分制。按结构、排版、材质、交互和路径列通过/有偏差/未测；量化指标需要定义方法与适用范围。硬约束失败不能被其他项的高分抵消。

没执行发布就写未上线。保留指定回滚版本；无清理授权不删旧包。
